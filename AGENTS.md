# Regras de Agente

- Ao criar specs ou planejar próximas tarefas, utilize **obrigatoriamente** a skill `to-spec`.
- Ao implementar layouts ou realizar mudanças visuais no frontend, utilize **obrigatoriamente** a skill `frontend-design`.
- Sempre que a estrutura de arquivos/diretórios do projeto for alterada (novos arquivos, renomeações, remoções), atualize **obrigatoriamente** a seção `📁 Estrutura do Projeto` no `README.md`.
- Qualquer script temporário deve ser criado em `sandbox/`.
